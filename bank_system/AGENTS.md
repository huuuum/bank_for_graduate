数据集为 bank-marketing 银行营销数据集（UCI 银行营销数据 + 社会经济上下文特征的版本），静态 csv 文件，**没有真实持续流入的实时业务数据**。

数据位于 `data/` 目录，共三张表：

| 文件 | 数据量 | 列数 | 用途 |
| --- | --- | --- | --- |
| `data/train.csv` | 22500 条 | 22 列（21 特征 + `subscribe` 标签） | **训练集**：Spark 离线清洗、特征工程、模型训练的数据源；也可作为 Kafka 生产者读取、循环发送模拟流的数据源 |
| `data/test.csv` | 7500 条 | 21 列（无 `subscribe` 标签） | **测试集**：用于离线模型评估 / 预测（需预测出 subscribe）；也可用于模拟「未见过的实时数据流」做 Flink 推理测试 |
| `data/submission.csv` | 7500 条 | 2 列（`id` + `subscribe`） | **结果提交样例**：竞赛提交格式参考，只含 id 与预测标签（当前全为 `no`），用于导出/填充预测结果、对照提交格式 |

## 三、完整技术栈清单

### 大数据层
- **Kafka**：消息中间件，作为流缓冲。Python 编写生产者读取 csv 循环发送消息，模拟实时数据流。
- **PyFlink**：实时计算引擎。消费 Kafka 数据，完成实时 ETL 清洗，加载训练好的机器学习模型做实时推理预测。
- **Spark（PySpark）**：离线批处理。负责原始数据集离线清洗、特征工程、数据集划分、训练预测模型（分类任务：客户是否会购买定期存款）。
- **MySQL**：存储：离线统计结果、Flink 实时预测输出结果、前端业务数据。
- **Hive**：不强制，可以不加；若论文要体现大数据组件，可仅简要提及，不作为核心运行依赖。

### 机器学习部分
- 任务：**二分类预测**，标签：客户是否认购定期存款（`subscribe`）
- 模型选择：优先传统机器学习（**逻辑回归 / 随机森林**），轻量、毕设好落地；**不使用大模型、多模态、YOLO、CLIP**
- 工作划分：Spark 离线完成特征工程与模型训练，导出训练完成的模型文件；Flink 算子加载该模型，对流内每一条客户数据做实时预测

### 后端 & 前端
- **SpringBoot**：Java 后端服务，读取 MySQL 中离线统计结果、Flink 实时预测结果，编写 RESTful 接口给前端调用
- **Vue**：前端页面，实现客户列表展示、实时预测结果看板、各类统计图表、客户预测风险视图
- 可视化全部由 Vue 前端渲染，**不使用 PowerBI**

## 四、完整项目全流程（严格顺序）

### 阶段 1：离线批处理流程（PySpark）
1. 读取 bank-marketing 原始 csv 数据集（`data/train.csv`）。
2. 离线数据预处理：缺失值处理、类别特征编码、数值特征规范化、异常值过滤。
3. 特征工程，筛选有效特征，划分训练集、测试集。
4. 训练二分类模型，评估指标：准确率、精确率、召回率、F1、混淆矩阵。
5. 将训练完毕的模型持久化保存到本地文件。
6. Spark 离线统计客户群体各类统计指标，写入 MySQL 数据库。

### 阶段 2：模拟实时数据流（Kafka 生产者 Python）
- 关键点：**没有真实业务流，模拟流**。
- 读取本地 csv（`train.csv`，可循环读取），逐行读取。
- 将每行客户数据转为 JSON 格式。
- 作为消息持续发送到 Kafka 指定 topic，模拟源源不断的银行客户业务数据流。

### 阶段 3：PyFlink 实时处理链路
1. Flink 消费 Kafka Topic 消息流。
2. Flink 算子完成实时 ETL：字段清洗、格式校验、特征转换（**和离线训练保持一致，特征处理逻辑必须对齐，否则预测效果错乱**）。
3. Flink 算子加载磁盘上已训练好的模型文件，对每条流入的客户流数据执行实时推理预测，输出预测结果：该客户是否大概率认购定期存款。
4. 将单条实时预测结果写入 MySQL。

### 阶段 4：SpringBoot 后端服务
- 连接 MySQL，封装接口：
  - 获取离线 Spark 统计报表数据接口
  - 获取 Flink 实时预测结果列表接口
  - 接收 Vue 前端 http 请求，返回 JSON 数据

### 阶段 5：Vue 前端页面
- 调用 SpringBoot 接口拉取数据。
- 页面功能：
  - 客户基础信息表格
  - 实时预测结果展示
  - 各类统计图表（年龄分布、职业分布、预测高意向客户占比等）
- 只做展示，不需要复杂交互。
